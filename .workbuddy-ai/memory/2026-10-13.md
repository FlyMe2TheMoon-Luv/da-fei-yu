### 踩到并已写进文档的新坑（HANDOFF.md 34–38 / HANDOFF-V2 13–16 / CLAUDE 31–36）

1. **`executeJavaScript` 在同一个全局作用域求值** —— 第二段脚本再写 `const x` 就报
   `Identifier 'x' has already been declared`，而且是主进程 UnhandledPromiseRejection，看不出跟脚本有关。
   **每段注入脚本都要包 IIFE**：`(() => { const x=…; return …; })()`。特别隐蔽（第一次能过、第二次才炸）。
2. **断言别用 `!== null` 判「量到了没有」** —— 注入脚本 early-return 时字段是 `undefined`，
   而 `undefined !== null` 是 `true` → 假通过。要用 `typeof x === 'number'`。
3. **`--isolated` 临时目录会被 Electron Cache 文件锁住**，`rmSync` 抛 `EBUSY` 把启动器搞崩。
   改成**带时间戳的目录名**，彻底避开「删不掉」。
4. **中文短标题取色「字符码累加模 N」会扎堆**（`吃药/买菜/健身` 同色）→ 用 FNV-1a。
5. **「窗口形态变了」≠「内容重画了」** —— 主进程切模式时界面要真的拉数据重绘，否则是空框。
6. **漏加共享样式会让控件掉到静态布局** —— `#btn-chat` 忘了加进 `#btn-settings,#btn-exit` 那个选择器，
   结果它没有 `position:absolute`，静态布局掉到窗口**左上角**。是 `test:exit` 的
   `elementFromPoint(3,3)` 抓到 `btn-chat` 才暴露的。
